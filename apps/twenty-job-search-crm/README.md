# Job Search for Twenty

A private Twenty app that turns Job_apply into a CRM-native job-search control center.

- Run All = discover, filter, assess, generate and verify. No submission.
- Review the company, fit score and exact PDF.
- Approve selected jobs or all shortlisted jobs.
- Apply All Approved starts the browser queue.
- CAPTCHA/legal/unknown flows go to attention instead of being guessed.

Configure `JOB_APPLY_ORCHESTRATOR_URL` and the optional secret `JOB_APPLY_ORCHESTRATOR_TOKEN`, then run `yarn twenty dev` against your Twenty workspace.
